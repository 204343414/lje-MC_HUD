🎮 MC 创造背包风格的 Q 菜单 — 效果预览

这是用网页模拟的样子（实际游戏里用的是 Minecraft 原版 widgets.png 贴图，会更还原）。 按 Q 弹出，9 列格子展示服务器上所有可生成的武器，鼠标悬停显示名字，点一下就把武器给到手上。

Creative Inventory[1/3] 滚轮翻页
点击格子获得武器 - Q 或 ESC 关闭
Pistol
实现要点：
• 按 Q 拦截 GMod 默认的 +menu，改弹这个面板
• 格子来自 list.Get("Weapon")，和 GMod 自带生成菜单同一个武器库
• 点格子执行 gm_giveswep <武器类名>，直接给到手上（像 MC 创造模式拿物品）
• 注意：这个菜单会和服务器交互（生成是真实动作），不像 HUD 那样完全隐形
